### Descripcion
El proyecto consiste en desarrollar una aplicacion en Python
para gestionar clientes, servicios y reservas de la empresa
ficticia Software FJ.

El sistema permite administrar:
- Registro de clientes.
- Reserva de salas.
- Alquiler de equipos.
- Asesorias especializadas.
- Confirmacion y cancelacion de reservas.
- Manejo de excepciones y validaciones.
- Registro de eventos y errores mediante archivos logs.
