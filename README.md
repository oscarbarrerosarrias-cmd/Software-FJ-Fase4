## 1. Descripción del proyecto

Software FJ es una aplicación desarrollada en Python que permite
administrar clientes, servicios y reservas de una empresa que ofrece
reservas de salas, alquiler de equipos y asesorías especializadas.

El sistema utiliza programación orientada a objetos y almacena
temporalmente la información mediante objetos y listas internas,
sin utilizar bases de datos.

## 2. Objetivo general

Desarrollar un sistema integral que permita gestionar clientes,
servicios y reservas mediante principios de programación orientada
a objetos y manejo avanzado de excepciones.

## 3. Tecnologías utilizadas

- Python 3.
- Visual Studio Code.
- Git.
- GitHub.
- Programación orientada a objetos.
- Módulo logging de Python.

## 4. Arquitectura del proyecto

- entidades.py: clase abstracta Entidad.
- clientes.py: gestión y validación de clientes.
- servicios.py: servicios especializados.
- reservas.py: administración de reservas.
- excepciones.py: excepciones personalizadas.
- main.py: ejecución y menú principal.
- logs/: registro de eventos y errores.

## 5. Principios de programación implementados

- Abstracción.
- Herencia.
- Encapsulación.
- Polimorfismo.
- Sobrescritura de métodos.
- Variantes de métodos mediante parámetros opcionales.
- Manejo de listas internas.
- Validaciones estrictas.

## 6. Manejo de excepciones

Se implementan excepciones personalizadas, bloques try/except,
try/except/else, try/except/finally y encadenamiento de excepciones.

Los eventos y errores se registran en logs/sistema.log.

## 7. Tipos de servicios

1. Reserva de salas.
2. Alquiler de equipos.
3. Asesorías especializadas.

## 8. Ejecución del programa

Se requiere Python 3 instalado.

Desde la terminal, ubicada en la carpeta principal del proyecto,
ejecutar:

python main.py

## 9. Demostración

El programa incluye una demostración automática de doce operaciones,
con registros válidos e inválidos, servicios y reservas exitosas y
fallidas.

## 10. Almacenamiento

El sistema no utiliza bases de datos. Los datos se mantienen en
listas y objetos durante la ejecución. El archivo de logs conserva
los registros de eventos y errores.
